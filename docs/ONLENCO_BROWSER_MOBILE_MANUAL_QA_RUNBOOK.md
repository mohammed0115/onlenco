# Onlenco — Browser / Mobile Manual QA Runbook
# دليل الاختبار اليدوي للمتصفّح والموبايل — Onlenco

_آخر تحديث: مرحلة 18.4D._ مرجع UAT:
[Final UAT Readiness](ONLENCO_UAT_READINESS_FINAL.md).

> هذا دليل **تشغيل يدوي** لفريق UAT يغطّي ما لا تغطّيه اختبارات Django (لا
> Playwright/browser tooling في المشروع): المتصفّح الحقيقي، الموبايل، RTL،
> المايك والصوت، والمكالمة الحيّة. **لا يستبدل** الاختبارات الآلية.

---

## 1. Purpose / الغرض
التحقّق يدويًا من تجربة الطالب الحقيقية على متصفّحات وأجهزة فعلية، خاصة المسارات
التي لا يلمسها test client: تشغيل الصوت، تسجيل المايك، مكالمة AI Tutor الحيّة،
تفاعلات اللمس، وتخطيط RTL — قبل توسيع UAT أو الإطلاق.

## 2. Scope / النطاق
- **داخل النطاق:** رحلة الطالب A0 (لوحة → كورس → درس → تقدّم → اختبار يومي →
  بوّابة الأسبوع)، AI Tutor (نص/رسالة صوتية/مكالمة)، الوسائط، RTL/موبايل،
  الأذونات/الأخطاء.
- **خارج النطاق:** لوحة المعلّم المتقدّمة، الدفع/الاشتراك العميق، Novels، PWA
  (مؤجّلة). محرّك Weekly Review الكامل (حاليًا بوّابة فقط).

## 3. Test Environment Requirements / متطلّبات البيئة
- بيئة UAT/staging تعكس الإنتاج (وسائط معتمَدة مرئية).
- **مفاتيح OpenAI/الصوت حقيقية في بيئة آمنة** (للأقسام 10–11 فقط؛ AI Tutor صوت/مكالمة).
- HTTPS فعّال (المايك يتطلّب secure context في المتصفّح).
- بيانات seed: `python manage.py seed_onlenco_beginner_48_units --confirm` (إن لم تكن مهيّأة).
- إعداد افتراضي: `DAILY_LISTEN_BUILD_ENABLED=False` (انظر القسم 7).

## 6. Student Journey Manual Tests / رحلة الطالب
1. تسجيل/دخول.
2. اختيار Beginner.
3. فتح اللوحة.
4. فتح كورس المبتدئين.
5. فتح أول درس.
6. التحقّق من صورة الغلاف (تظهر، غير مكسورة).
7. التحقّق من رسوم المفردات/القواعد/الاختبار.
8. تشغيل صوت الدرس.
9. تشغيل/إيقاف الصوت أكثر من مرة.
10. إكمال الدرس.
11. التحقّق من تحديث التقدّم.
12. فتح الاختبار اليومي.
13. إجابة عنصر صحيح.
14. إجابة عنصر خاطئ.
15. التحقّق من الـfeedback والدرجة.
16. إكمال ثلاثة دروس.
17. التحقّق من ظهور بطاقة مراجعة الأسبوع.
18. فتح AI Tutor نصّي.
19. إرسال رسالة A0 بسيطة («Hello»).
20. التحقّق من دعم إنجليزي بسيط/عربي.
21. اختبار رسالة صوتية.
22. اختبار مكالمة صوتية.
23. خروج ثم دخول مجددًا.
24. التحقّق من **عدم** إجبار placement إذا اختار Beginner مسبقًا.

## 7. Daily Quiz Manual Tests / الاختبار اليومي
- `/daily/` يفتح ويعرض 6 عناصر A0 مناسبة (لا عناصر >A0).
- النقر/اللمس على خيار يعمل بسلاسة (لا تأخّر، لا تكبير غير مقصود).
- إجابة صحيحة ⇒ feedback إيجابي؛ خاطئة ⇒ feedback سلبي **بلا كشف الإجابة الصحيحة**.
- **`correct_answer` لا يظهر في نص الصفحة/الـDOM** (افحص View Source).
- الدرجة النهائية منطقية (بالصحّة لا بالإكمال).
- (listen_build) — انظر §7-b.

### 7-b. listen_build (افتراضيًا False)
- في UAT العادي **لا يظهر** (الإعداد opt-in). اذكر ذلك للفريق.
- إذا فعّله الفريق في **بيئة آمنة** (`DAILY_LISTEN_BUILD_ENABLED=True`):
  - A1 يرى عنصر listen_build؛ **A0 لا يراه**.
  - الطالب يسمع الجملة عند الضغط على زر الصوت.
  - الكلمات تظهر **مبعثرة**.
  - الترتيب الصحيح ⇒ correct؛ الخطأ ⇒ incorrect.
  - الجملة الكاملة (`correct_answer`) **لا تظهر كنص** في الصفحة.

## 8. Weekly Review Gate Manual Tests / بوّابة الأسبوع
- قبل إكمال 3 دروس: **البطاقة لا تظهر**.
- بعد 3 دروس: **البطاقة تظهر**.
- الزر **معطَّل** («المراجعة قريبًا») وآمن — **لا رابط مكسور**.
- الطالب يستطيع متابعة الدرس/الوحدة التالية بشكل طبيعي.
- ظهور البطاقة **لا يغيّر** التقدّم.

## 9. AI Tutor Text Manual Tests / المساعد النصّي
- إرسال «Hello» ⇒ ردّ يصل.
- الردّ A0: **إنجليزي بسيط + دعم عربي قصير**.
- **لا أسماء مزوّد/JSON/أسماء ملفات/`___`** في الردّ.
- الشات النصّي **لا ينقص عدّاد الدقائق** المعروض.
- الرسائل الطويلة/الفارغة تُعالَج برسالة لطيفة.

## 10. AI Tutor Voice Message Manual Tests / الرسالة الصوتية
> يتطلّب مفاتيح حقيقية + HTTPS + بيئة آمنة.
- أول طلب إذن مايك يظهر.
- تسجيل يبدأ/يتوقّف.
- حالة الرفع/المعالجة تظهر.
- ردّ صوتي للمعلّم يُشغَّل.
- **الدقائق المتبقية تنقص** بعد الرسالة الصوتية.
- إعادة إرسال نفس الرسالة (retry) **لا تخصم مرتين**.

## 11. AI Tutor Voice Call Manual Tests / المكالمة الحيّة
> يتطلّب مفاتيح حقيقية + HTTPS + بيئة آمنة.
- بدء المكالمة: المعلّم **يتكلّم أولًا** (لا ينتظر الطالب).
- العدّاد التنازلي للدقائق يظهر ويعمل.
- **الصفحة لا تتحدّث (refresh) أثناء المكالمة** (لا انقطاع للجلسة).
- إنهاء المكالمة يخصم الوقت الفعلي.
- **الضغط على إنهاء مرتين لا يخصم مرتين**.
- عند نفاد الدقائق: رسالة عربية لطيفة «انتهى وقت المساعد الذكي اليومي…» وإيقاف آمن.
- مكالمة placement (إن وُجد مسارها) **لا تخصم** دقائق AI Tutor العادية.

## 12. Mobile / Responsive Checks / الموبايل والاستجابة
- عرض ~360px: لا overflow أفقي، لا نص مقصوص.
- أهداف اللمس مريحة (≥44px) للأزرار/الخيارات.
- صور الدرس تتكيّف (لا تمدّد/تشويه).
- مشغّل الصوت قابل للاستخدام باللمس.
- اللوحة/الكورس/الدرس/اليومي تتصفّح بسلاسة على الموبايل.

## 13. RTL / Arabic UI Checks / واجهة عربية وRTL
- النصوص العربية تُحاذى يمينًا، تخطيط RTL سليم.
- الخلط عربي/إنجليزي لا يكسر المحاذاة (أرقام/كلمات إنجليزية ضمن جمل عربية).
- الأزرار ثنائية اللغة مقروءة وغير متداخلة.
- الأيقونات/الأسهم في الاتجاه الصحيح لـRTL.
- لا نصوص قوالب «خام» ظاهرة (`{% %}` / `{# #}`).

## 14. Media Playback Checks / تشغيل الوسائط
- الأغلفة/الرسوم المعتمَدة تظهر؛ **لا وسائط معلّقة/فاشلة تظهر للطالب**.
- الصوت يُشغَّل ويتوقّف ويُعاد عدّة مرّات بلا تعطّل.
- لا أيقونة/رابط صورة مكسور.
- سرعة الصوت طبيعية (لا تسريع غير مقصود).

## 15. Error / Offline / Permission Checks / الأخطاء والأذونات
- **رفض إذن المايك**: رسالة واضحة، لا تعطّل، إمكانية إعادة المحاولة.
- **السماح بالإذن** بعد الرفض يعمل.
- انقطاع الشبكة أثناء المكالمة/الرفع: حالة خطأ لطيفة، لا تجمّد.
- تحديث الصفحة في منتصف عملية: لا فقدان بيانات حرج/لا حالة عالقة.
- Safari iPhone و Android Chrome تحديدًا (سلوك المايك يختلف بينها).

## 16. Pass/Fail Criteria / معايير النجاح والفشل
| المعيار | نجاح | فشل |
|---|---|---|
| الرحلة الأساسية | تكتمل بلا تعطّل | أي خطوة تمنع التقدّم |
| الوسائط | معتمَدة فقط تظهر وتُشغَّل | وسائط مكسورة/معلّقة تظهر |
| الاختبار اليومي | تصحيح صحيح + لا تسريب إجابة | إجابة مكشوفة أو درجة خاطئة |
| الدقائق | خصم صحيح بلا double-bill | خصم مزدوج/خصم نص/خصم placement |
| RTL/موبايل | تخطيط سليم على 360px | overflow/نص مقصوص/قالب خام |
| الصوت/المكالمة | تشغيل/تسجيل/إنهاء سليم | تجمّد/refresh أثناء المكالمة |

**Severity للفشل:** blocker (يمنع الرحلة) ⇒ يوقف Go.

## 18. Go/No-Go Checklist / قائمة القرار
- [ ] الرحلة الأساسية تكتمل على Chrome + Safari iPhone + Android Chrome.
- [ ] الوسائط المعتمَدة تظهر وتُشغَّل؛ لا وسائط معلّقة.
- [ ] الاختبار اليومي يصحّح ولا يسرّب الإجابة.
- [ ] بوّابة الأسبوع تظهر بعد 3 دروس، آمنة معطّلة.
- [ ] AI Tutor نصّي يردّ بلغة A0 مناسبة بلا token تقني.
- [ ] رسالة صوتية/مكالمة: مايك/تسجيل/تشغيل/إنهاء سليم بلا double-bill.
- [ ] النفاد يعطي رسالة عربية لطيفة.
- [ ] RTL/موبايل سليم على ~360px.
- [ ] لا أخطاء blocker مفتوحة.

> **Go** عند تحقّق كل ما سبق على الأجهزة الإلزامية بلا blocker.
