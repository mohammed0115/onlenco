# تقرير Prompt 16.6D — إصلاح تصميم صفحات الطلاب والتفاصيل

**التاريخ:** 2026-06-04 · **نسخة الأصول:** `p166d-student-detail-ux-20260604`

## 1. الملخص التنفيذي
أُعيد بناء صفحة `‎/admin/students/<id>/‎` بالكامل من تجميع عناصر مبعثر إلى لوحة تشغيلية منظّمة: تبويبات عربية كـ chips، بطاقات ملخّص، شبكة محتوى متوازنة، جدول تقدّم بشريط نسبة، و**لوحة إجراءات مدمجة بأزرار طبيعية الحجم** (بدل الأزرار الضخمة). كل النصوص عُرّبت. **لا تمرير أفقي** على أي صفحة (مؤكَّد بمتصفح حقيقي: `doc=0, body=0`).

## 2. المشاكل من صور الإنتاج
- أزرار ضخمة (تمديد/إعادة تحديد/تعطيل) كلٌّ في كارت منفصل.
- كروت طويلة فارغة وLayout غير متوازن، فراغات كبيرة.
- تبويبات وعناوين بالإنجليزية داخل واجهة عربية (Overview, Payments, Send notification…).
- جدول Learning Progress غير مرتّب.
- احتمال overflow أفقي وRTL غير مريح.

## 3. السبب الجذري
- قالب الأدمن لم يُرحَّل لنظام الـ action-panel المدمج `.ta-*` (الموجود والمستخدم في صفحة المعلّم)، فبقي على `.action-box` القديم (كارت لكل زر).
- نصوص إنجليزية صلبة في القالب (بلا شرط لغة).
- لا شبكة محتوى موحّدة ولا بطاقات ملخّص.

## 4. الإصلاحات المنفّذة
- **Action Panel:** ترحيل إلى `.ta-aside / .ta-mini / .ta-btn` (المُختبَر سابقاً في صفحة المعلّم) — أزرار 42–46px، عرض كامل داخل الكارت لا بطوله، **منطقة خطر `.ta-danger`** منفصلة. حارس CSS: `.student-actions .ta-btn { min-height:42px; max-height:52px; height:auto }`.
- **التبويبات:** `.tabs-wrap > .tabs-list > .tab-chip` — chips عربية قابلة للتمرير أفقياً داخل الحاوية فقط، مع `is-active` واضح.
- **الكروت:** `.content-grid` (عمودان) + `.card-wide`، وبطاقات ملخّص (الاشتراك/المستوى/XP/السلسلة/آخر دخول)، وempty states نظيفة.
- **الجداول:** Learning Progress داخل `.table-wrap` مع `.progress-mini` (شريط نسبة) و`badge` للحالة، وأعمدة طويلة تلتف بأمان.
- **RTL/الموبايل:** خصائص logical، الـ content-grid وbطاقات الملخّص تتراصّ عمودياً ≤1100px، الـ sidebar drawer مغلق، لا overflow.
- **التعريب الكامل** (القسم 11): كل العناوين والأزرار والتبويبات ثنائية اللغة.
- **رفع النسخة** إلى `p166d-student-detail-ux-20260604` في `control.css`.
