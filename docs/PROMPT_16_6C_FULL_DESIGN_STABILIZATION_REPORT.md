## 1. الهدف

إنهاء تثبيت تجربة إنشاء المحتوى وتصميم اللوحات بحيث:
- لا يُجبر أي معلّم أو مشرف عادي على كتابة JSON خام إطلاقًا.
- تختفي مشكلة التمدّد الأفقي (horizontal overflow) على الجوال وفي وضع RTL.
- تُغلَّف كل الجداول داخل بطاقات قابلة للتمرير أفقيًا بأمان.
- تبقى كل الصلاحيات وبوابة موافقة الطالب وسير النشر/الاعتماد كما هي دون أي مساس.

## 2. بوابة المعلّم (teacher_portal)

### 2.1 معالجات إنشاء/تعديل المحتوى (Wizards)
أُعيد بناء نموذجي **إنشاء/تعديل الكورس** و**إنشاء/تعديل الدرس** كمعالج من 5 خطوات:

| العنصر | الوصف |
|--------|-------|
| `.tp-wizard-stepper` | شريط الخطوات العلوي (أزرار قابلة للنقر) |
| `.tp-wizard-pill` | زر الخطوة (مع `.is-active`) |
| `.tp-wizard-panel` | لوحة محتوى كل خطوة (تظهر واحدة فقط) |
| `.tp-wizard-actions` | شريط الإجراءات السفلي (السابق / التالي / حفظ) |

**خطوات الكورس:** 1) المعلومات الأساسية · 2) الوصف والأهداف · 3) الوسائط (صورة غلاف + فيديو تعريفي مع معاينة فورية) · 4) الهيكل (وحدات/دروس إرشادية) · 5) المراجعة قبل الحفظ (بطاقة طالب حيّة).

**خطوات الدرس:** معلومات الدرس · المحتوى ثنائي اللغة · الوسائط (صوت/فيديو/PDF/ورقة عمل) · الأولوية والمهارة · المراجعة.

- لا حقل JSON خام لأي معلّم. كل الحقول مرئية مُسمّاة ثنائية اللغة (عربي/إنجليزي).
- منطق التنقّل عبر JavaScript بسيط داخل القالب (إظهار/إخفاء اللوحات + تحديث بطاقة المراجعة لحظيًا).
- الحقول مطابقة 100% لحقول `TeacherCourseForm` و`TeacherLessonForm` الحالية — لا تغيير في نموذج البيانات.

### 2.2 الأنماط والتجاوب
- `teacher.css` / `teacher_forms.css`: تقسيم بطاقات، آمن لـ RTL، قصّ التمدّد الأفقي.
- رفع إصدار الكاش إلى `?v=p166c-design-20260603`.
- كل جداول البوابة مُغلّفة بـ `.table-wrap`.

## 3. لوحة الإدارة (platform_admin)

### 3.1 الهيكل والتجاوب (`control.css`)
- `.control-main { min-width: 0 }` + شبكة `grid-template-columns: 16rem minmax(0, 1fr)` لمنع تمدّد العمود الرئيسي.
- `overflow-x: hidden` / `clip` على الـ shell لمنع تمدّد الصفحة.
- درج الجوال (drawer) بعرض `84vw` بدل `100vw` (كان يسبّب overflow).
- لوحات إجراءات `.ta-*` للصفوف.
- إخفاء زر الهامبرغر والـ overlay على الديسكتوب (`@media min-width:1024px`).

### 3.2 الجداول
- كل جدول إداري (الطلاب، المعلّمون، الكورسات، الخطط…) مُغلّف بـ `.table-wrap` داخل بطاقة.

### 3.3 باني أسئلة تحديد المستوى (Placement)
- نموذج بصري بخطوات (`pq-builder` / `pq-stepper`) بدل JSON.
- تحقّق ودود: رسالة واضحة لو السؤال فارغ بالعربية والإنجليزية.
- حقل **JSON المتقدّم** ظاهر للمطوّر/السوبر-أدمن فقط (`is_superuser`).
- تحديد جماعي: تفعيل / تعطيل / حذف للأسئلة المختارة + «تحديد الكل».
