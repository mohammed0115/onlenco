# Execution Order

Run these prompts in this exact order:

1. Requirements Traceability Matrix
2. End-to-End Scenario Tests
3. Weekly Assessment Audit
4. Speaking and Pronunciation Audit
5. AI Failure Mode Tests
6. User Isolation Security Tests
7. Subscription and Payment Audit
8. REST API Contract Audit
9. Curriculum Quality Audit
10. Final Launch Gate Review
11. Acceptance Rules

After each prompt, require the AI/code assistant to provide:

- Files inspected
- Files changed, if any
- Tests added
- Commands run
- Test results
- Evidence from code paths
- Remaining gaps
- Whether it is safe to continue

Do not move to the next validation prompt until the current one has produced evidence.
