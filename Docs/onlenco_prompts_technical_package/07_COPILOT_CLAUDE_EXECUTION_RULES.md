# 07_COPILOT_CLAUDE_EXECUTION_RULES.md

استخدم هذه التعليمات مع أي أداة برمجة AI قبل إعطائها أي Prompt.

```text
أنت تعمل على مشروع Onlenco.
لا تنفذ بشكل عشوائي.
اقرأ المطلوب كاملاً.
افحص المشروع الحالي أولاً.
لا تكسر أي ميزة موجودة.
لا تكرر الكود.
لا تضع business logic داخل views.
استخدم services/selectors.
اكتب tests.
حدّث docs.
بعد التنفيذ أعطني تقرير واضح.

قبل كتابة أي كود:
1. افحص بنية المشروع.
2. افحص التطبيقات الموجودة.
3. افحص settings.
4. افحص migrations.
5. افحص tests.
6. اقترح خطة قصيرة.
7. ثم نفذ.

بعد التنفيذ:
1. اذكر الملفات التي أنشأتها.
2. اذكر الملفات التي عدلتها.
3. اذكر migrations الجديدة.
4. اذكر APIs الجديدة.
5. اذكر الاختبارات الجديدة.
6. اذكر أوامر التشغيل.
7. اذكر أي مشاكل متبقية.

ممنوع:
- كود بدون tests.
- views ضخمة.
- logic داخل templates.
- أسماء عشوائية.
- كود غير قابل للتوسع.
- ربط مباشر بمزود AI واحد بدون interface.
- تجاهل العربية والإنجليزية.
- تجاهل RTL/LTR.
```
